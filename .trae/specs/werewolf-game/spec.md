# 狼人杀游戏 - 产品需求文档

## 概述
- **Summary**: 设计并实现一个基于网易狼人杀规则的网页版狼人杀游戏，支持12人局（1人+11AI），使用大语言模型驱动AI玩家，提供丰富的游戏板子和身份配置功能。
- **Purpose**: 为用户提供一个可以与AI进行狼人杀游戏的平台，体验完整的狼人杀游戏流程和玩法。
- **Target Users**: 狼人杀爱好者，希望在没有足够真人玩家的情况下也能体验完整的狼人杀游戏。

## 目标
- 实现12人局狼人杀游戏，支持1人玩家和11个AI玩家
- 提供三种游戏板子：狼王守卫、风声谍影、预女猎白
- 实现完整的游戏流程，包括警长竞选、发言、投票等环节
- 支持AI玩家的个性化人设和提示词配置
- 实现狼人夜间交流功能
- 提供美观的游戏界面，参考网易狼人杀的UI设计

## 非目标（范围外）
- 不实现语音系统，仅支持文字交流
- 不实现真实玩家之间的联机对战
- 不实现会员、VIP等付费功能
- 不实现复杂的用户系统，仅支持基础的游戏功能

## 背景与上下文
- 网易狼人杀是一款流行的多人推理游戏，拥有丰富的游戏模式和角色
- 本项目参考网易狼人杀的规则和流程，实现一个AI驱动的版本
- 使用MiniMax-M2.7大语言模型来模拟AI玩家的行为和发言

## 功能需求
- **FR-1**: 游戏板子管理
  - 支持三种游戏板子：狼王守卫、风声谍影、预女猎白
  - 每种板子有固定的角色配置

- **FR-2**: 身份分配
  - 支持玩家指定自己的身份
  - AI玩家随机分配剩余身份

- **FR-3**: 游戏流程管理
  - 实现完整的游戏流程：夜晚行动 → 警长竞选 → 白天发言 → 投票放逐 → 重复直到游戏结束
  - 支持警徽传递和警长发言顺序特权

- **FR-4**: 狼人夜间交流
  - 狼人可以在夜间交流战术
  - 确定由谁悍跳，是否上警等策略

- **FR-5**: AI玩家管理
  - 为每个AI玩家设置不同的人设和提示词
  - AI玩家使用大语言模型生成发言和行动
  - 提供AI提示词配置页面

- **FR-6**: 知识库管理
  - 为AI玩家提供公共知识库，包括游戏术语和规则
  - 支持知识库的更新和扩展

- **FR-7**: 游戏界面
  - 美观的游戏界面，参考网易狼人杀的UI设计
  - 清晰的角色状态和游戏流程显示
  - 支持文字聊天功能

## 非功能需求
- **NFR-1**: 性能要求
  - 游戏响应时间快，AI发言生成时间不超过3秒
  - 支持实时聊天和游戏状态更新

- **NFR-2**: 可扩展性
  - 系统设计应支持添加新的游戏板子和角色
  - AI提示词配置应易于扩展和修改

- **NFR-3**: 用户体验
  - 界面美观，操作流畅
  - 游戏规则清晰，新用户容易上手

- **NFR-4**: 稳定性
  - 系统应稳定运行，避免崩溃和错误
  - 妥善处理API调用失败等异常情况

## 约束
- **技术**: 使用MiniMax-M2.7大语言模型，通过MINIMAX-API进行调用
- **依赖**: 依赖外部API服务，需要确保API Key的安全使用
- **平台**: 网页端应用，支持主流浏览器

## 假设
- 用户已经了解基本的狼人杀游戏规则
- 外部API服务稳定可用
- 用户设备具备基本的网络连接和浏览器功能

## 验收标准

### AC-1: 游戏板子功能
- **Given**: 用户进入游戏设置页面
- **When**: 用户选择一种游戏板子
- **Then**: 系统应正确加载对应板子的角色配置
- **Verification**: `programmatic`

### AC-2: 身份指定功能
- **Given**: 用户进入游戏设置页面
- **When**: 用户选择指定自己的身份
- **Then**: 系统应将指定身份分配给用户，剩余身份分配给AI
- **Verification**: `programmatic`

### AC-3: 游戏流程完整性
- **Given**: 游戏开始
- **When**: 系统按照狼人杀规则执行游戏流程
- **Then**: 系统应正确执行夜晚行动、警长竞选、白天发言、投票放逐等环节
- **Verification**: `programmatic`

### AC-4: 狼人夜间交流
- **Given**: 游戏进入夜晚阶段，用户为狼人
- **When**: 狼人进行夜间交流
- **Then**: 系统应显示狼人交流界面，AI狼人应参与交流
- **Verification**: `programmatic`

### AC-5: AI玩家表现
- **Given**: 游戏进行中
- **When**: AI玩家需要发言或行动
- **Then**: AI玩家应根据人设和提示词生成合理的发言和行动
- **Verification**: `human-judgment`

### AC-6: 提示词配置
- **Given**: 用户进入AI设置页面
- **When**: 用户修改AI提示词
- **Then**: 系统应保存修改后的提示词，并在游戏中应用
- **Verification**: `programmatic`

### AC-7: 界面美观性
- **Given**: 用户进入游戏界面
- **When**: 用户查看游戏界面
- **Then**: 界面应美观，布局合理，操作流畅
- **Verification**: `human-judgment`

## 未解决的问题
- [ ] 如何平衡AI玩家的智能程度，避免过于机械或过于聪明
- [ ] 如何处理API调用失败的情况，确保游戏可以继续进行
- [ ] 如何优化AI发言生成的速度，减少用户等待时间
